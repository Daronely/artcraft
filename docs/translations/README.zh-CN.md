## 🌟 项目概述

**ArtCraft** 是一款专为交互式 AI 图像和视频创作设计的开源 IDE。支持 2D 构图与 3D 场景布局，并整合各类最适合你工作流的生成式大模型。通过直观的可视化工具，将传统的文字输入（Prompting）升华为真正的精准与可重复的艺术创作（Crafting）。

---
