## 🌟 Descripción General

**ArtCraft** es el IDE de código abierto para la creación interactiva de imágenes y vídeos con IA. Compón en 2D, prepara escenas en 3D y escoge los modelos generativos que mejor se adapten a tu flujo de trabajo. Transforma el simple uso de prompts en una verdadera *creación artística visual (Crafting)* con herramientas pensadas para resultados precisos y reproducibles.
